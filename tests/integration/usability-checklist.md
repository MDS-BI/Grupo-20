# SC-003 · Checklist de usabilidad (tareas de gestión de clientes)

## Criterios medibles

- Cada participante ejecuta cuatro tareas: **Crear**, **Editar**, **Buscar** y **Eliminar** una entidad/cliente.
- Tiempo máximo por tarea: **300 s (5 min)**. Se registra el tiempo real en segundos.
- Una tarea es exitosa solo si el resultado esperado queda persistido y no aparece un error de validación.
- Se registra si el participante solicitó ayuda y los errores observados.
- Umbral de aprobación: **al menos el 90 % de las 20 tareas (18/20)** completadas con éxito.
